# assets-src

Raw source files copied from the rustyAC repo on 2026-10-10. The site never serves these directly.
Optimised versions (compressed model, AVIF/WebP screenshots) get built from them.

- `logo/rustyACGrokNOBG.png`: the rustyAC logo (transparent background), from `rustyAC/things/`
- `models/f2004/f2004.glb`: the F2004 (15.8 MB, 236k tris, all 46 textures embedded), from `rustyAC/ignored/2004-ferrari-f2004/source/`. Gitignored because of its size.
- `screenshots/`: real rustyAC screenshots, from `rustyAC/docs/port/*.png`
